# Problem Solving Skills: Human vs. GAI

본 저장소는 위 과제의 AI의 선택에 인간이 개입하는 경우의 결과물을 저장하는 저장소 입니다.

선정한 문제: 테트리스 게임 만들기
사용 LLM 모델: Gemini 3.1 Pro
LLM 사용 환경: Gemini 웹사이트

공통 사항: 결과 확인을 보다 쉽게 하기 위해 결과물은 웹사이트 형태로 고정, 코드의 변화과정을 확인할 수 있도록 2가지 방식의 결과물 모두 각각의 레포지토리를 만들어 관리, 첫 프롬프트는 다음으로 고정
“웹 환경에서 동작하는 테트리스 게임을 단계적으로 만들어줘. 그리고 다음 단계에 대한 선택지를 제시해줘”

과제 진행 방식
GAI만 사용하는 경우 다음의 규칙을 따름
1. LLM이 제시하는 선택지중 첫 번째 선택지 만을 골라 진행한다.
2. 문법 오류의 경우 IDE의 에러 메시지를 그대로 전송한다.
3. 런타임 에러의 경우 가능한한 문제 상황만을 전송한다.

AI 선택에 인간이 개입하는 경우 다음의 규칙을 따름
1. LLM이 제시하는 선택지는 무시하고 자신이 생각하는 방향에 대해 서술해 진행한다.
2. 문법 오류의 경우 다음과 같은 과정을 거쳐 해결한다. 자신의 사전지식으로 해결 시도 → 인터넷 검색으로 해결 시도(AI 검색 결과는 활용하지 않음) → AI 검색 결과를 활용해 해결 시도
3. 런타임 에러의 경우 문제 상황과 문제의 원인으로 추정되는 요인들을 함께 전송해 해결을 시도한다.
